Virtual Fluid Mechanics Lab — Major Losses in Pipe Flow

A full-stack virtual replica of the Major Losses in Pipe Flow experiment — students run the apparatus, get their calculations checked, test their understanding, and walk away with a generated report.

Stack

React + Vite + Tailwind + Express

Experiment

Major Losses in Pipe Flow

Modules

Apparatus, validation, quiz, report

Output

Auto-generated PDF report

The problem it solves

Access to the physical pipe-flow rig is limited to lab hours, and students who fall behind or want extra practice have no way to revisit the experiment. This lab rebuilds the apparatus and its logic in the browser so the experience — and the learning — isn't tied to a time slot.

Method

Built as a full-stack React + Vite + TailwindCSS application with an Express.js backend. The apparatus is rendered as an animated SVG that responds to live parameter input, a calculation-validation module checks a student's working against the underlying major-loss equations, and a quiz/viva module lets them self-test before the backend compiles a PDF report of the session.

Result

A complete four-part flow: run the apparatus, check your working, test your understanding, download the report.

The result reads less like a static explainer and more like a working lab station — the kind a student could use unsupervised and still leave with a valid report.
