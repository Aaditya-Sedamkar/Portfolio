Virtual Fluid Mechanics Lab

A full-stack virtual replica of the Major Losses in Pipe Flow experiment — students run the apparatus, get their calculations checked, test their understanding, and generate a report.

StackReact + Vite + Tailwind + Express
ExperimentMajor Losses in Pipe Flow
ModulesApparatus, validation, quiz, report
OutputAuto-generated PDF report

How it's built

A full-stack React + Vite + TailwindCSS application with an Express.js backend. The apparatus is rendered as an animated SVG that responds to live parameter input, a calculation-validation module checks a student's working against the underlying major-loss equations, and a quiz/viva module lets them self-test before the backend compiles a PDF report of the session.

Why it exists

Access to the physical pipe-flow rig is limited to lab hours, and students who fall behind or want extra practice have no way to revisit the experiment. This lab rebuilds the apparatus and its logic in the browser so the experience isn't tied to a time slot.

Ships as a complete four-part flow: run the apparatus, check your working, test your understanding, download the report — built to work unsupervised and still produce a valid result.
